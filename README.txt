LOVE LETTER WEBSITE

Files:
- index.html : website structure and text
- style.css  : colours, layout, responsive design and animations
- script.js  : envelope opening and closing interaction

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a browser, or use VS Code Live Server.
3. Click the wax seal to open the letter.

Photo placeholders:
Search for the elements with class "photo-placeholder" in index.html.
To use your own pictures, replace each placeholder div with:
<img class="your-photo" src="images/photo1.jpg" alt="Memory photo">

The original photos, floral decorations and Spotify artwork from the TikTok video
were not supplied separately, so this version recreates the visible layout and
uses placeholders for those assets. The Spotify link opens a Spotify search page.
